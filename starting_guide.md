# Starting K-Panel

1. Open a terminal in this folder.
2. Run the launcher script for your OS:
   - **macOS**: `./start-in-mac.sh`
   - **Linux**: `./start-in-linux.sh`
   - **Windows**: double-click `start-in-windows.bat` (or run it from a terminal)
3. The script installs Python dependencies, then starts:
   - Backend: http://127.0.0.1:8877
   - Frontend: http://127.0.0.1:8080/k-panel.html (opens automatically)
4. Press `Ctrl+C` in the terminal to stop both servers.

That's it — pick your agents, set your LLM API key, and start a discussion.
