About K-Panel

K-Panel is a lightweight demo of an "agentic system": a virtual panel of AI experts (each with their own persona and specialty) that discuss a topic you give them, turn-by-turn. Once every expert has spoken, their entire discussion is synthesized into a structured Product Requirements Document (PRD) in Markdown — capturing the value proposition, target audience, brand tone, features, visual direction, and copy guidance from the whole panel. That PRD is then used to generate a visually rich, single-page website prototype.

How to use it:
1. Click "Agents" to pick at least two experts for your panel, or click "New Agent" to create your own custom expert (saved instantly on the backend as a reusable agent — no restart needed).
2. Click "Key" to set your own OpenAI-compatible API key (and optionally a custom base URL / model / user) — it's stored only in your browser. Use "Help me choose a provider" if you're not sure which service or settings to use.
3. Type your idea or topic and start the discussion; the experts will take turns automatically, then a PRD is written from everything they said.
4. Click "View PRD" to read/download the generated Markdown document, or "Visualize" to turn that PRD into a single-page website prototype (watch the HTML stream in live), then download it if you like it.

This is a teaching example, not a production system — your API key is sent directly from the browser to the backend on every request.
