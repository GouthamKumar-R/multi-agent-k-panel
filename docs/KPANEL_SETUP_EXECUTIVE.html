Step 01 · Participant readiness

Get the workshop files and prerequisites

Download or extract the repository, confirm Python 3.9+, and use an internet-connected machine.

Clone or enter the supplied folder
git clone https://tinyurl.com/netappnasscom
cd multi-agent-k-panel/k-panel
python3 --version

# If using the supplied ZIP:
cd k-panel-netapp-nasscom/k-panel

Required

  • Python 3.9 or newer
  • Internet access
  • The k-panel folder with launch scripts
  • A modern web browser
Success: The terminal is inside k-panel and Python reports version 3.9+.
If blocked: Re-extract the ZIP or install Python before continuing.
Step 02 · Start locally

Launch K-Panel for your operating system

The launcher creates venv, installs requirements.txt, and starts both local services.

Run one platform command
# macOS
chmod +x start-in-mac.sh
./start-in-mac.sh

# Linux
chmod +x start-in-linux.sh
./start-in-linux.sh

# Windows
start-in-windows.bat

Open after launch

  • Frontend: http://127.0.0.1:8080/k-panel.html
  • Backend: http://127.0.0.1:8877
  • The browser usually opens automatically.
Success: The K-Panel page loads and the backend URL responds.
If blocked: Check backend.log, static.log, and ports 8877/8080.

Step 04 · Workshop activity

Run a multi-agent panel discussion

Choose complementary specialists, give them one concrete product challenge, and let the final turn synthesize their discussion into a PRD.

Participant flow
1. Select 2–3 agents
2. Enter a focused discussion topic
3. Start the discussion
4. Watch each expert contribute
5. Review the generated Markdown PRD

Suggested panel

  • Brand Manager
  • Copywriter
  • Graphic Designer
  • Marketing Analyst
Success: Every selected agent contributes and K-Panel produces a structured PRD.
If blocked: Check the LLM connection in Step 3, then retry the failed turn.
Step 05 · Build an artifact

Create a custom agent and visualize the PRD

Extend the panel with a deeptech role, rerun the discussion, then turn its PRD into a live single-page prototype.

Participant flow
1. Click New Agent
2. Define name, role, and system prompt
3. Add the agent to the panel
4. Complete the discussion
5. Click Visualize
6. Download the generated HTML

Deeptech role ideas

  • Identity Infrastructure Lead
  • Autonomous Robotics Architect
  • AI Safety & Cybersecurity Specialist
Success: A custom persona contributes and the PRD becomes a downloadable web prototype.
If blocked: Use a capable model with enough output quota and retry visualization.
