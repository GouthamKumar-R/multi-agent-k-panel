Step 01 · Participant readiness

Get the workshop files and prerequisites

Download or extract the repository, confirm Python 3.9+, and use an internet-connected machine.

Clone or enter the supplied folder
git clone https://github.com/GouthamKumar-R/multi-agent-k-panel.git
cd multi-agent-k-panel
python3 --version
If using the supplied ZIP
cd k-panel-netapp-nasscom/k-panel

Required

  • Python 3.9 or newer
  • Internet access
  • The repository folder containing the launch scripts
  • A modern web browser
Success: The terminal is inside the folder containing the launch scripts and Python reports version 3.9+.
If blocked: Re-extract the ZIP or install Python before continuing.
Step 02 · Start locally

Launch Multi-Agent Blueprint from your operating system

The launcher creates venv, installs requirements.txt, and starts both local services.

Run commands for your platform
macOS
chmod +x start-in-mac.sh
./start-in-mac.sh
Linux
chmod +x start-in-linux.sh
./start-in-linux.sh
Windows
start-in-windows.bat

Open after launch

  • Frontend: http://127.0.0.1:8080/k-panel.html
  • Backend: http://127.0.0.1:8877
  • The browser usually opens automatically.
Success: The K-Panel page loads and the backend URL responds.
If blocked: Check backend.log, static.log, and ports 8877/8080.

Step 04 · Workshop activity

Run the multi-agent panel and visualize the PRD

Choose complementary specialists, generate a structured PRD from their discussion, then turn it into a live single-page prototype.

Participant flow
  1. Select 2–3 agents.
  2. Enter a focused discussion topic.
  3. Start the discussion and watch each expert contribute.
  4. Review the generated Markdown PRD.
  5. Click Visualize.
  6. Download the generated HTML prototype.

Suggested panel

  • Brand Manager
  • Copywriter
  • Graphic Designer
  • Marketing Analyst
Success: Every selected agent contributes, a structured PRD is produced, and its web prototype can be downloaded.
If blocked: Check the LLM connection and output quota in Step 3, then retry the failed turn or visualization.
Step 05 · Optional extension

Optional: Create a custom persona agent

If time allows, extend the panel with a reusable deeptech persona tailored to your product challenge.

Optional participant flow
  1. Click New Agent.
  2. Define its name, role, and system prompt.
  3. Save the persona.
  4. Add it to the panel.
  5. Rerun the discussion if workshop time permits.

Deeptech role ideas

  • Identity Infrastructure Lead
  • Autonomous Robotics Architect
  • AI Safety & Cybersecurity Specialist
Success: The custom persona is saved and available for future panels.
If blocked: Check that the name, role, and system prompt are complete, then save again.
